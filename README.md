# Pathfinder Simulator

A simple program to allow users to simulate combat and create custom characters, monsters, or NPCs for the TTRPG Pathfinder.

## WIP
- Player class
- Monster class
- NPC class
- Feat list
- Classes for Players (Bard, Warlock, etc.)
- Templates from Pathfinder (Elf ancestry, Criminal background, etc.)
